# Project Memory

## Mission
- Build hands-on familiarity with Deep Agents features through practical experiments.

## Current Setup
- Main model comes from `.env` via `MODEL_NAME` and `API_KEY`.
- Web search is available through the `internet_search` tool.
- The agent includes two specialized subagents: `researcher` and `coder`.

## Working Preferences
- Prefer concise answers with practical examples.
- For time-sensitive topics, prefer recent sources and include concrete dates.
- Include source URLs when web tools are used.

## Safety
- Never store API keys, tokens, passwords, or credentials in memory files.
